# LabLink - Making College Laboratories Accessible
Built for PromptWars 2026

## Problem
Lab equipment is expensive, idle, and hard to book. Students face conflicts and delays.

## Solution
AI-powered booking platform with AI Conflict Detection, Smart Equipment Matching, and Real-time Booking.

## Tech Stack
- Google AI Studio, Firebase Auth, Firestore, Gemini AI, React, TypeScript, Tailwind CSS

## Features
- Book Multi-GPU Workstations, SEM, 3D Printers
- AI checks for time conflicts and suggests alternatives
- Secure Google Sign-in
- Try Demo Booking + Validation for testing

## Testing Done
1. Booking appears in My Bookings instantly
2. Double-booking triggers AI Conflict Detection
3. Google Login/Logout works
